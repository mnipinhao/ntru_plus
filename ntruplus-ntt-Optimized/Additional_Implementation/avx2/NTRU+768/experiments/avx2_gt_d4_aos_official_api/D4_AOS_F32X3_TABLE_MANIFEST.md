# F32X3 table manifest

V2 tables are mathematically determined by the coordinate document: length-32 root is `omega96^3`, DFT3 root is `omega96^32`, inverse tables use reciprocal roots and factors `32^-1`, `3^-1`, `beta_b^-i`, and CRT delta inverse. Each consumption vector repeats its four-coefficient quartic group. Checked-in stage-order AVX2 tables remain pending the intrinsics implementation; the V1 generated manifest is preserved unchanged.
