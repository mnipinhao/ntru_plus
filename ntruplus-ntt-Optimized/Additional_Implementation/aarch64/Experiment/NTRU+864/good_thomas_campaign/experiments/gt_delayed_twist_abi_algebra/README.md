# M5T: delayed-twist transform-domain ABI algebra

This experiment is separate from the Forward-local M5S DAG.  It changes no
assembly and is never linked by Production.

It tests the proposed leaf ABI

```
F'_k = d_k F_{pi(k)}
```

before allowing a pending factor to cross Forward into BaseMul.  The exact
basis-vector proof rejects complete omission of `lambda^s`: the untwisted
NTT9 and FR-0 transforms are related by a diagonal-plus-row-permutation only
when `lambda` belongs to the order-9 subgroup generated by `eta`.  None of the
32 GT864 `(top,column)` lambdas does.

One useful subfamily does close: replacing `lambda` by `lambda*eta^a` is a
pure row rotation.  `test_delayed_twist.c` applies that ABI to all 864
transform-boundary coefficients, rotates the BaseMul zeta consumer, restores
the inverse map, and compares it with the ordinary FR-0 multiplication path.
This validates the shared phase/layout ledger, but it does not remove the base
lambda twist and therefore does not yet satisfy the delayed-twist performance
gate.
