# M5T-A results

The general delayed scalar-factor ABI fails its first algebra gate.

- all 32 `(top,column)` lambdas were checked by exact 9-column basis matrices;
  untwisted NTT9 has zero diagonal-plus-permutation matches to FR-0.
- the reason is structural: every lambda lies outside the order-9 subgroup
  generated by eta.  Removing `lambda^s` moves evaluation to another coset;
  it does not multiply each output leaf by a scalar.
- all 288 `lambda -> lambda*eta^a` cases do close as the row permutation
  `physical k -> logical k+a mod 9`, with pending factor exactly one.
- the C reference covers all 864 transform-boundary coefficient slots, 96
  zero/boundary/random trials, and all nine rotations: 746,496 coefficient
  comparisons, zero mismatch through Forward, rotated-zeta BaseMul, and
  inverse restoration.

The surviving row rotation is useful layout freedom, but it removes no base
lambda twist and provides no cost reduction by itself.  No assembly or
Production path was changed.
