# P34 — non-materializing Inverse DAG decision gate

P34 does not write candidate assembly.  It rebinds the current production
Inverse-to-ternary path, checks the real acceptance interval of its P8 raw
ternary consumer, and searches the existing terminal representative resets for
arithmetic that can be deleted without another scratch or routing boundary.

Run `python3 audit.py` to regenerate `audit-results.json`.  Pi 5 stage results
and the selected successor are summarized in `RESULTS.md`.
